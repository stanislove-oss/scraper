# 📚 Books Parser

## 🎯 Цель проекта
Проект предназначен для автоматического сбора информации о книгах с сайта [Books to Scrape](http://books.toscrape.com/).  
С помощью парсинга каждая карточка книги преобразуется в структурированные данные (название, цену, рейтинг, наличие и описание).  
Результаты сохраняются в текстовый файл, а также могут собираться по расписанию каждый день.

---

## 🚀 Функциональность

- Извлечение данных о книге с отдельной страницы (`get_book_data`)
- Сбор информации со всех страниц каталога (`scrape_books`)
- Автоматический запуск парсинга по расписанию (каждый день в 19:00) с помощью библиотеки `schedule`
- Возможность сохранять результаты в файл `books_data.txt`
